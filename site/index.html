Features

Built for reading history, not rewriting it.

git-sea never writes to your repositories. Open as many as you like, explore their history, and close them knowing nothing changed.

Node-canvas graph

Commits flow left to right on a dotted canvas with pan, zoom, pinch and fit. Nodes show the commit type, label, hash and ref badges.

Fast on large repos

The topological walk and the lane layout run in Rust and stream to the UI in chunks. A cached layout reopens in milliseconds.

Details and diffs

Metadata, clickable parents, changed files with rename detection, and unified or split diffs with syntax highlighting.

Live updates

Watches your repository and working copy, fetches remotes in the background and animates new commits as they arrive.

Search and command palette

Find commits by message, author or hash, filter the graph, and reach every action from the keyboard.

CI at a glance

See your GitHub Actions and GitLab CI workflows, their latest runs, and the commits where they would start.

Performance

Views

One history, four ways to look at it.

Every view is a projection of the same graph, so switching between them keeps your place and your selection.

Graph

Cards up close, tiles at medium zoom, dots far away.

Topology

Linear runs fold into single nodes, leaving only the shape.

Timeline

Commits placed on real time, to see when work actually happened.

Minimap

The whole history in one strip, with your viewport on top.

Install

Get started.

Download

Grab the .dmg from the latest release and drag git-sea to Applications. The app isn't notarized yet, so on first launch right-click it and choose Open, or run:

xattr -dr com.apple.quarantine /Applications/git-sea.app

Build from source

You need Rust (stable), Node.js with pnpm, and the Xcode Command Line Tools.

# clone and run
git clone https://github.com/ehystiv/git-sea
cd git-sea
pnpm install
pnpm tauri dev

# release build
pnpm tauri build
